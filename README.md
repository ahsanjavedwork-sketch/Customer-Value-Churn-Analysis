# Customer Value & Churn Risk Analysis

## Overview
Analyzed customer data in Excel to explore customer lifetime value, churn,
purchase behavior, and customer segments.

## Tools
- Microsoft Excel
- Formulas and PivotTables
- Dashboard visualizations

## Key Findings
- The dataset contains 9,999 customer records.
- The high-value customer group had an 8.1% churn rate, compared with about
  26% for the medium- and low-value groups.
- Average order value was about $61 for active customers and $33 for churned
  customers.

## Files
- `Customer_Value_Churn_Analysis.xlsx` — analysis workbook and dashboard

## Notes
This project presents descriptive analysis of the dataset. The findings show
patterns and associations; they do not establish causes or predict future churn.
